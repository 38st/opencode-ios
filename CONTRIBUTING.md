# Contributing

Issues are welcome: bug reports, problems with a particular opencode server version, and feature requests. Report security problems privately instead, as described in [SECURITY.md](SECURITY.md).

## Pull requests

Outside pull requests can't be merged yet. The app is licensed under the GPL-3.0, and its App Store build needs rights that the GPL alone does not grant, so code contributions will need a contributor licence agreement. Until one is in place, please open an issue to discuss a change.

## Development

- [README.md](README.md): building, running and testing the app.
- [Tools/README.md](Tools/README.md): the sandboxed opencode server, the scripted model, fixtures, contract checks and UI smoke tests.
- [AGENTS.md](AGENTS.md): code rules.
- [SPEC.md](SPEC.md) and [ARCHITECTURE.md](ARCHITECTURE.md): product decisions and design.
