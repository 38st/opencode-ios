# Security policy

The app stores credentials for opencode servers, and those servers can run commands on your computer. Please report vulnerabilities privately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue. Include the commit or build, the opencode server version, and the steps to reproduce.

## Scope

- The iPhone and iPad app in this repository.
- The push plugin and relay, once they land (milestone M5).

Problems in opencode itself belong to the [opencode project](https://github.com/anomalyco/opencode).

## Supported versions

Nothing has been released yet. Fixes go to `main`.
